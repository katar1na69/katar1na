САЙТ-ПЕРЕХОДНИК ДЛЯ БЬЮТИ-БЛОГЕРШИ

Как открыть:
1. Распакуй beauty_transition_site.zip.
2. Открой папку в Visual Studio Code.
3. Открой index.html.
4. Запусти через расширение Live Server (если установлено) или открой index.html в браузере.

Как настроить под блогершу:
- В index.html замени "beauty by katya" и "Beauty by Katya" на нужное имя.
- TikTok, Telegram и email уже заполнены данными, которые ты прислал. Замени общие ссылки Instagram и YouTube, если хочешь их добавить.
- Чтобы сменить фото, замени URL в атрибуте src у изображения с классом portrait.
- Фоновые изображения трёх карточек меняются в style.css в правилах .tile-one, .tile-two и .tile-three.

Важно:
- Сейчас в карточках стоят общие ссылки на главные страницы платформ. Замени их перед публикацией.
- Для загрузки сайта в интернет можно использовать GitHub Pages, Netlify или другой статический хостинг.
- Google Fonts и внешние фотографии требуют подключения к интернету.
